# 安全与隐私

## 密钥边界

- 模型密钥只允许放在服务端 `.env`。
- 禁止在 `VITE_*` 变量中保存任何密钥。
- `.env`、`.env.*`、Ngrok 配置和 SQLite 数据库均不进入 Git。
- 仓库不包含真实用户密钥、手机号、录音或上传音频。

## 公开仓库检查

提交前执行：

```powershell
npm audit
rg -n "api[_-]?key|secret|token|password|authorization" . -g "!node_modules/**" -g "!package-lock.json"
```

GitHub 仓库公开后启用 Secret Scanning，并确认 `.env.example` 只包含空值或示例值。

## 远程模型安全

- 远程文本长度受到请求模型限制。
- 模型响应必须是 JSON 对象。
- 情绪和动作经过白名单归一化。
- 回复长度限制为 160 字符。
- 远程超时、限流、非 JSON 或非法状态都会回退本地路由。
- 服务端只连接显式配置的 HTTPS 基地址，不执行模型返回的代码或 URL。

## 浏览器隐私

- 页面默认使用本地语义，不发送聊天文本。
- 只有启用远程模型后，文本才会发送给第三方。
- 语音识别由浏览器提供，音频不在应用中存储或上传。
- 实时天气需要用户主动点击，并且只向 Open-Meteo 发送经纬度。
- 自定义图片保存在浏览器 localStorage，不写入 SQLite。

## 部署安全

- Ngrok 提供 HTTPS 公网入口。
- Ngrok authtoken 保存在用户本机配置目录。
- 一键脚本只记录进程 ID 和公网 URL，不记录 token。
- 停止脚本只清理脚本自己启动的进程。
- 不建议在公共演示环境输入真实隐私、账号或财务信息。
