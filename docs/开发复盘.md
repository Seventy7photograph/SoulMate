# AI 开发复盘

## 使用的 AI 工具

- ChatGPT: 需求拆解、交付清单和测试场景整理。
- Codex: 前后端实现、Three.js 骨骼修复、语义路由、自动化测试和部署脚本。
- Playwright: 桌面与移动端真实浏览器验收。
- Impeccable: 布局检测和视觉质量复核。

## 实际耗时

累计约 4 小时。主要工作包括首版实现、四套 KayKit 模型接入、头部跟随与待机动作修复、移动端遮挡调整、语义路由扩展、自动化验收、中文文档和 Ngrok 部署。

## AI 原稿不够好并手动修正的细节

### 1. 3D 骨骼跟随造成人物变形

AI 最初把头部跟随直接逐帧累加到骨骼旋转上，同时手动调整上半身和髋部。由于动画混合器不一定每帧重置对应骨骼，旋转会持续累积，出现上半身扭转、下半身不动和重心角度过大的问题。

修正方式是先保留动画混合器的原始四元数，再叠加有界的头部偏移；同时取消髋部强制旋转。动作结束后接回已经运行的待机周期，不再从第一帧重播。

### 2. 本地语义规则覆盖过窄

AI 最初只识别少数情绪关键词，未命中的“早上好”“早餐吃什么”都会返回同一条“我在听”。问题不在页面渲染，而在本地路由和运行中的旧 API 进程。

修正后增加了问候、饮食、夸奖、亲密、道歉、焦虑、工作学习、娱乐、旅行、天气、无聊、告别、身份询问和开放式陈述等场景，并加入 Pollinations、Gemini 和 OpenAI 兼容接口的可选远程增强。

### 3. 移动端气泡遮挡聊天记录

AI 原稿把提示气泡固定在左上角，聊天消息增多后会与气泡重叠。修正后把气泡移到角色头部上方，聊天历史默认折叠、渐隐并只保留最新内容，同时提供展开按钮。

## 结论

AI 加速了实现和验证，但涉及骨骼层级、状态生命周期和移动端遮挡时，不能直接接受第一次生成结果。最终版本通过真实浏览器截图、接口请求、单元测试和 E2E 回归确认关键行为。
