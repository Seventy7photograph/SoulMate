# 本地语义与免费模型说明

## 设计目标

演示环境必须在没有 API Key、没有外网、远程模型限流或模型返回非法 JSON 时继续工作。因此语义链路采用“远程增强、本地下限”的结构：远程模型成功时提供更开放的问答能力，失败时直接使用本地意图路由。

## 本地意图覆盖

本地路由会同时判断关键词、语气、疑问句结构和常见中英文表达。当前覆盖的场景包括：

- 问候、重逢与告别。
- 早餐、午餐、晚餐与饥饿。
- 夸赞、好消息、满足与开心。
- 亲密互动、感谢和道歉。
- 难过、焦虑、压力、孤独和疲惫。
- 生气、反感与冲突语气。
- 睡眠、困倦与休息。
- 工作、学习、考试、面试和项目压力。
- 音乐、影视、阅读、游戏、运动、旅行和宠物。
- 天气、无聊、身份询问与能力询问。
- 一般疑问句和开放式陈述。
- `hello`、`thanks`、`sorry`、`bye` 等常见英文短句。

同一条意图规则包含多个回复模板，根据输入内容稳定选择措辞。它不会声称自己是云端大模型，也不会编造实时数据。

## 情绪与动作约束

模型输出只允许六种情绪和六种动作：

```text
emotion: IDLE | HAPPY | SHY | SAD | SLEEPY | ANGRY
action: IDLE | JUMP | DANCE | WAVE | PUNCH | SIT
```

远程模型返回 `friendly`、`greeting` 等非白名单值时，服务端会根据同一段文本调用本地路由补齐合法状态。回复文本限制在 160 字符以内，置信度会被限制到 0 到 1。

## 免费模型选项

### Pollinations 公共接口

```env
LLM_PROVIDER=pollinations
LLM_MODEL=openai
```

无需 API Key，适合无密钥演示。公共接口可能出现限流、排队、非 JSON 输出或网络不可达，因此只作为增强选项，不替代本地路由。

### Gemini 免费额度

```env
LLM_PROVIDER=gemini
GEMINI_API_KEY=服务端密钥
GEMINI_MODEL=gemini-2.5-flash
```

密钥只保存在服务器环境变量中，不会进入前端 bundle。

### OpenAI 兼容接口

```env
LLM_PROVIDER=openai-compatible
LLM_BASE_URL=https://服务地址/v1
LLM_API_KEY=服务端密钥
LLM_MODEL=模型名称
```

可以接 Groq、OpenRouter、Ollama、LM Studio 等兼容接口。Ollama 本地运行时可省略远程费用。

## 数据流

1. 浏览器提交文本。
2. FastAPI 根据环境变量选择本地或远程适配器。
3. 远程调用失败时，服务端直接返回本地分析结果。
4. 服务端对情绪、动作、回复长度和置信度做归一化。
5. 前端更新情绪、动作、光影、对话气泡和会话记录。

## 隐私说明

- 默认 `LLM_PROVIDER=local`，用户文本不会离开本机。
- 启用 Pollinations、Gemini 或远程 OpenAI 兼容接口后，文本会发送到对应服务方。
- API Key 只允许配置在服务端 `.env` 中。
- 不要把 `.env`、Ngrok authtoken 或供应商密钥写入 Git。
